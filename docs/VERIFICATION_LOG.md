### Найденные и исправленные проблемы методологии теста (для протокола)

1. Равномерный стимул на весь холст → рост не ограничивается нигде,
   ткань залила все 576 клеток холста — тест обесценен (восстановление
   тривиально, когда цель "залить всё" достижима откуда угодно).
2. Локализованный стимул, но зона стимуляции не соприкасалась с seed →
   рост не мог начаться (клетки растут только рядом с уже живыми) —
   тест выродился (0.0 п.п. разницы между рост-вкл/выкл).
3. Исправлено: зона стимула связана с seed, но меньше всего холста
   (12×12 из 24×24 + пограничный спилловер = 192 из 576) → génuine
   bounded homeostatic рост, осмысленный тест.

## Компонент 2: Быстрая ассоциативная память (гиппокамп)

| Claim | Статус | Комментарий |
|---|---|---|
| Online Hebbian запись без backprop | ✅ | Подтверждено чтением кода (`W += beta*outer`), и косвенно нашей PC-релаксацией (энергия сходится корректно) |
| SDR (kWTA ~5-6%) снимает интерференцию, 95%+ на 80+ фактах | 🔴 не подтвердилось на масштабе | `core/sdr_hippocampus.py` + `experiments/hippocampus_retention_sweep.py`, с нуля. SDR причинно лучше плотной памяти на каждом N (изолировано — тот же Hebbian rule, разница только в разреженности). НО: v1-число "95%+" верно только при N≤~150 — на реальном масштабе retention падает: N=1000→67.9%, N=2000→38.4%, N=4000→18.2% (при sdr_dim=1024). Ёмкость масштабируется с sdr_dim предсказуемо (N=2000: dim=1024→38.4%, 2048→60.7%, 4096→78.2%, 8192→86.8%) — не фундаментальный потолок, но v1 заявление "решена интерференция" было преждевременным по масштабу |
| VSA-binding, 97.7% на unseen-парах | ✅ с нуля, скорректировано | `core/vsa_binding.py` (circular convolution/correlation, HRR по Plate 1995) + `experiments/vsa_capacity_sweep.py`. Первый прогон до K=32 дал подозрительные ~100% — тест был слишком лёгким (маленький пул сущностей = decode почти всегда тривиален). Расширил до K=512: реальная ёмкостная кривая — 99.8% на K=32, 87.3% на K=64, 52.3% на K=128, 10.1% на K=512 (dim=1024). "The Binding Problem" — вопрос ёмкости суперпозиции, не бинарное "решена/не решена" |
| Retention на масштабе 1000+ фактов | ✅ есть данные, результат отрицательный при фиксированном размере | См. строку выше — измерено честно, и число неутешительное без консолидации |

**Статус:** ✅ SDR-гиппокамп реализован и проверен, ✅ ёмкость масштабируется
с dim (проверено, не предполагается). 🔴 v1-заявление "решена интерференция"
скорректировано: верно только на маленьком масштабе, который v1 тестировал.
**Архитектурный вывод, подтверждённый данными:** консолидация (компонент 3)
не опциональна — фиксированный гиппокамп разумного размера физически не
держит тысячи фактов, значит перенос в структурный субстрат (компонент 1)
обязателен для реальной ёмкости, а не просто "приятная биологическая деталь".
**Следующий шаг:** VSA-binding с нуля (см. ниже), затем сон на PC-релаксации.

Найден и исправлен реальный баг: PC-релаксация с relax_lr=0.1 расходилась на задачах сложнее spiral-теста (энергия росла после ~40 шагов вместо убывания, |W| росла неограниченно) — уменьшенный relax_lr + weight decay дали гладкую сходимость на изолированном тесте.
